Pocketknife is a programming language with a unique but readable syntax designed to help you solve problems.

It's pipeline paradigm works like a flow chart, passing data from input to output and transforming it along the way. If you can describe your problem as a series of steps, pocketknife caern probably help you.

Its aim is to be something in between the shell and a Python script. Solve a problem, throw it away, move on.

```
>range -50 50
|mul 2
|abs
<>
|sort asc
:print
^
```
